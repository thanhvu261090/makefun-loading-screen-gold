A sharp, funny loading-screen tip for stressed developers and AI coding agents — the kind of line that makes a tired developer laugh mid-build, then feel seen.

> "Tip: the loading bar is not stuck. Your AI agent is reading your code, sighing, and quietly rewriting it for the third time."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–200 characters, not only whitespace, a single line with no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
